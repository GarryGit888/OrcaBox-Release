# OrcaBox

OrcaBox 是面向创作者与创意团队的本地素材管理器，支持图片、视频、音频、Lottie、3D 模型、字体和文档等多种格式的索引、预览、检索与整理。

## 官网

[访问 OrcaBox 官方官网](https://orcabox.app/)

官网使用 OrcaBox 官方域名，CNB Release 提供主要下载，GitHub Release 作为备用下载。

## 主要能力

- 直接索引本地文件，不复制或移动原始素材
- 40+ 文件格式预览与元数据读取
- 图片、音频、视频、Lottie 和 3D 模型工作流
- 标签、合集、评分、搜索与批量整理
- 本地 AI 分析与颜色搜索
- macOS 与 Windows 桌面版本
