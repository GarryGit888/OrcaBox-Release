# 拼图图

OrcaBox 外部插件，提供独立窗口中的网格拼图与横向/纵向长图拼接。

## 功能

- 导入本地图片，支持多选与拖放；可在格子中替换、移除和拖动排序。
- 网格拼图支持 2–16 张图片；长图可纵向或横向排列。
- 双击网格图片进入变换编辑，拖动图片调整位置、拖动四周控制点缩放；效果会用于最终导出。按 Enter 或点击“完成”保留调整，按 Escape 取消。
- 设置画布比例、边距、间距、圆角及背景色。
- 导出 PNG、JPG 或 WebP，可选 768、1080、1536、2160 像素档位和有损格式质量。
- 导出会把 OrcaBox 本地图片 URL 规范化为受保护的素材协议地址，以便安全地合成到画布。
- 通过素材右键菜单把已选图片带入面板；所有拼接与导出均在本地浏览器画布中完成。

## 构建

在 OrcaBox_Plugins 仓库运行：

```sh
npm run build:plugin -- --plugin=com.orcabox.jigsaw
npm run package:plugin -- --plugin=com.orcabox.jigsaw
```
