# OrcaBox 1.4.3 发行说明

发布日期：2026-11-19

> 本版本把重点放在「浏览素材时的流畅度与加载速度」。我们逐项复现并修复了滚动过程中几类长期存在的体验问题：快速甩动时出现整屏空白、滚走的素材滚回来又重新显示加载中、滚动停稳瞬间整屏闪一下、鼠标滚轮一格一格地卡、HTML 素材比其它格式明显更慢、打开来源目录时几十个子文件夹挨个加载内容。与此同时新增「媒体文案提取」插件与素材面板回到顶部按钮，并加快了 Office 文档预览。macOS 与 Windows 版本现已补齐到同一发行页。

## 素材浏览性能

- **减轻快速切换来源目录的后台负载**：切走目录时取消旧列表和封面查询，网格预热优先处理当前视口。标签统计和缩略图缓存路径检查移出主线程，减少大库或外置盘浏览时的停顿。
- **快速滚动不再出现空白**：此前快速甩动时视口会短暂变成空白，看不到卡片也不知道滚到了哪里。现在无论甩动多快，视口内始终有素材卡片与文件名可见；快滚期间使用轻量卡片（缩略图 + 名称 + 时长）以保证每帧都能跟上，滚动停稳后立即恢复为完整卡片，悬停预览、选中、右键、拖拽等交互不受影响。已用真实库（12 万素材、外置盘）实测：瀑布流、自适应网格、列表布局在惯性甩动下均无空白帧。
- **滚回来的素材不再重新加载**：已经显示过缩略图的素材，滚走再滚回来会直接出现，不再回落到「加载中」占位，也不会重放淡入动画。缩略图缓存有效期由 5 分钟延长到 30 分钟，并额外记住每张卡片实际显示过的图片地址，即使缓存条目被回收也能立即恢复。
- **滚动停稳时不再整屏闪一下**：修复了每次滚动开始与结束时可见视频卡、音频卡被整体重建的问题（表现为停稳瞬间卡片闪一下、淡入动画重放）。现在滚动前后卡片保持不变。
- **鼠标滚轮恢复顺滑**：此前鼠标垂直滚轮由应用自行接管滚动位置，绕过了系统的滚动合成，表现为一格一格地跳、且每格都要排队等界面渲染完成。现在垂直滚轮交还给系统原生滚动，滚动与界面渲染互不阻塞；水平滚轮、罗技 MX Master 拇指轮缩放、触底上滑加载更多这些手势全部保留。
- **HTML 素材加载大幅提速**：此前网格里每张 HTML 卡片都会实时加载一个完整网页，一屏十几到二十几个网页同时加载，既慢又拖累滚动。现在网格改用后台渲染好的静态截图，只有选中和打开预览的卡片才加载实时网页。实测一屏 15 张 HTML 卡片从「长期空白」变为首个采样点即全部有图，该区域滚动中位帧 17ms、95 分位 18ms。
- **文档与代码类素材滚动中即开始加载**：不再等到滚动完全停稳才读取内容，滚动过程中会以低优先级队列读取文本，停下时内容通常已经就绪。
- **打开来源目录不再挨个加载子文件夹内容**：此前子文件夹卡片直接用原图当封面，一个 56 像素的小封面要去解码一张 5K 大图，GIF 封面还会播放动画，几十个文件夹叠加起来非常卡。现在封面一律使用已生成的缩略图（静态、体积小），缺失的由后台补齐并在随后几秒内自动出现。

## 新增功能

- **媒体文案提取插件**：新的外部插件把音视频里的口播内容转成文字稿。可添加库内素材或本地文件，选择语音识别模型后批量转写，结果可直接用于文案整理与二次创作；插件面板支持单独指定本次转写使用的模型，不影响其它功能的语音识别配置。
- **素材面板回到顶部按钮**：快速向上滚动时，素材面板底部居中会出现回到顶部按钮，点击直接回到列表顶部；静止约 1.5 秒后自动隐藏，不遮挡内容。
- **素材卡片名称更完整**：卡片名称现在会显示文件扩展名并按可用宽度自适应换行（最多两行），长文件名不再被无提示地截断。
- **代码类素材彩色预览**：代码文件的卡片预览带语法着色，浏览时更容易区分文件类型。

## 优化改进

- **Office 文档预览加速**：Excel、Word、PowerPoint 的预览文件按需生成并缓存，重复打开同一文档明显更快；组件下载与预览状态提示更清楚。
- **来源文件夹卡片**：卡片按面板宽度自适应排列，数量多时不再挤压；文件夹磨砂与斜切边缘表现更自然；文件夹内切换子目录的响应速度提升。
- **文件夹搜索记录最近访问**：在文件夹选择与搜索中会记住最近访问位置，减少重复定位。
- **大素材库启动更快**：优化了启动阶段的查询与后台任务调度，素材量很大的库启动等待更短，后台索引不再与界面争抢。
- **浅色主题与音频预览界面**：浅色主题下的面板层次与对比度修正，音频预览界面细节对齐统一设计语言。
- **素材卡片选中边框**：选中描边由 2 像素细化为 1.5 像素，选中态更精致且不挤压卡内内容。
- **AI 画布生成产物命名**：AI 画布生成结果的命名更清晰，便于在库中辨认与检索。

## 问题修复

- **难解码或慢盘上的视频悬停预览卡住**：悬停预览遇到解码困难或读取缓慢的素材时，会在一到两秒内改走静帧预览，不再停在首帧只剩播放头移动；已知不适合内联擦洗的素材在同一会话内直接使用静帧，避免每次悬停都重复付出超时代价。
- **网页收藏封面与缩略图显示**：修复网页收藏条目的封面缓存不更新、缩略图不显示的问题。
- **外置硬盘素材监听恢复**：外置盘短暂断开后重新接入时，素材变更监听会自动恢复，不再需要重启应用。
- **资源库启动加载竞态**：修复启动阶段资源库数据与服务初始化竞争导致偶发空白或数据不全的问题。
- **拖拽导入状态残留**：修复拖拽导入过程中取消或中断后卡片状态残留、下次导入表现异常的问题。
- **语音识别与 AI 擦除后台进程恢复**：后台进程异常退出后可以正确恢复，不再需要手动重启应用。
- **下载器引擎错误提示**：网页视频下载所需引擎自动安装失败时，现在会给出脱敏后的真实原因（例如校验清单返回 403、代理不可用），而不是笼统的「自动下载引擎失败」；错误里的账号密码会被替换为占位文本。
- **AI 标签界面中英文切换**：修复界面语言在中英文之间切换后，AI 标签相关文案仍停留在旧语言的问题。
- **反推面板状态恢复**：重新打开反推面板时会恢复上次状态，不再每次都回到初始状态。
- **批量裁剪导出格式判断**：修正批量裁剪在特定格式组合下导出格式判断错误的问题。
- **Windows 打开方式**：修复 Windows 上「打开方式」无法启动、或列出的应用不完整的问题。
- **Windows 独立面板与文件夹卡片**：设置等独立面板的标题栏控件与面板底色衔接；来源目录的文件夹卡片封面在 Windows 上保持清晰。

## 获取更新

1.4.3 发布后，可在 OrcaBox 的「设置 → 概览 → 关于与更新」中检查更新，也可从「帮助与支持」打开同一入口。macOS 自动更新使用架构匹配的 ZIP 载荷（Apple Silicon / Intel 各自一份），人工安装请下载 DMG；Windows 自动更新使用 NSIS 安装器，另提供 Portable 免安装版。

## 平台差异与当前开发状态

- **本次发布范围**：macOS（Apple Silicon 与 Intel 双架构）和 Windows x64。macOS 两个架构都提供 DMG 安装包与用于自动更新的 ZIP 载荷；Windows 提供 NSIS 安装器、blockmap 与 Portable 免安装版。
- **Windows**：Windows x64 包由 macOS 交叉构建生成，已通过目录结构、原生模块、媒体运行时和更新清单校验；安装、升级、Portable 与原生播放行为仍需在真实 Windows 主机完成最终验收。
- **功能一致性**：本次的性能修复与界面改动均位于 macOS 与 Windows 共享的渲染与主进程代码，Windows 版发布时同步生效；跨平台窗口外观差异（标题栏融合、自绘窗口控件）按各平台既有实现分别维护。
- **原始文件安全**：以上所有性能优化只影响派生缩略图与界面渲染，不会移动、改写或重新编码素材原文件；缩略图与海报缓存在应用数据目录，删除后可重新生成。
