# OrcaBox 1.3.1 更新说明

发布日期: 2026-10-04

## 本次更新

- 详情面板信息卡显示设置：单选的信息卡区域可一键隐藏或恢复，多选时各批量卡片可单独开关（设置 → 浏览 → 详情面板卡片）。
- 应用内「新增功能」引导：更新后帮助按钮出现气泡引导与角标，可翻页的功能卡片介绍每次更新。
- 资源网格鼠标滚轮改为线性直接滚动，快速滚动更跟手；触控板与键盘导航不变。
- 原生播放自愈：加载停滞时自动回退浏览器引擎继续播放，恢复后可切回；Windows 修复 mpv 黑屏后仍占用播放路由的问题。
- 模型下载：多文件进度聚合显示，切换下载源不再清零；手动放入的模型可被正确识别。
