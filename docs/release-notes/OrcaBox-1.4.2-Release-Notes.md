# OrcaBox 1.4.2 发行说明

发布日期：2026-11-03

> 本版本带来新的内置插件「图片批量裁剪」：统一比例批量出图，AI 视觉模型定位每张图的主角中心；同时带来「视频质检」插件：信号级检测与 AI 视觉识别为视频做交付前体检。自 1.4.2 起，外部插件不再随安装包捆绑分发，改为通过插件目录独立供应与更新。界面方面，通知改为可悬停展开的堆叠卡组，「模型与用量」面板按统一仪表盘设计语言改版并新增功能分布与模型排行视图。此外修复视频快捷操作无法旋转的问题，修复相机竖拍照片的网格缩略图方向，并完善外部语音运行时安装任务的关闭收敛。

## 新增功能

- **资产库图标与显示名称可自定义**：切换面板“...”菜单「更改图标与名称…」上传图标（拖拽/选择/粘贴，缩放平移取景，正方形固定圆角显示）并修改显示名称（仅显示名，不重命名文件夹）。
- **图片批量裁剪插件**：新的内置插件打开独立面板——左侧图片队列、中间裁剪舞台、右侧比例预设。AI 视觉模型定位每张图的主角中心（本地视觉模型优先，可级联外接端点/云端 API，结果按文件指纹缓存），裁剪以锚点为准取最大同比例框，中心点可拖动微调；底部「开始批量裁剪」带实时进度条与逐张扫过动画。副本命名为「原名-宽x高」写入源图片同目录，不覆盖原文件；HEIC 自动转 JPG、BMP 转 PNG，其余格式保持原格式并保留 ICC 色彩配置；完成后自动入库并刷新素材网格。
- **视频质检插件**：新的外部插件为单个或多个视频做交付前体检。ffmpeg 信号级检测在本地单遍解码完成：黑帧、冻结帧、静音、削波、响度（EBU R128 LUFS/真峰）、隔行扫描与全量解码完整性（坏帧/截断）；开启「AI 视觉识别」后，引擎在黑帧结束点、冻结中点与均匀抽样时刻抽帧，交本地视觉模型判别坏帧/花屏、色偏、过曝、模糊等问题并附抽帧缩略图，AI 未配置时自动跳过并注明。报告含通过/警告/不通过结论徽标、12 项指标卡、问题列表与异常时间轴；检测项阈值可在面板内调整。**支持把问题点一键导入 DaVinci Resolve 当前时间线**：按问题类型着色（黑帧=蓝、冻结帧=青、静音=黄、音频=柠檬黄、解码错误=红、隔行=天蓝、AI 识别=紫），标题带时间区间、详情进备注。在素材库多选视频右键「视频质检」直达，或从工具栏打开面板添加库内视频/本地文件，队列串行可停止。
- **AI 打标签与描述可切换云端模型**：两项功能可分别选择本地或云端视觉端点与模型，配置入口同时位于“设置 → AI 智能 → 素材识别模型”和“帮助与支持 → 模型与用量 → 模型管理 → 素材识别模型”。云端模式支持图片、GIF 与视频抽帧识别；模型 ID 留空时使用端点默认模型。选择云端后失败会明确报错，不会自动改用本地标签；音频转写仍由本地语音模型完成。旧配置默认保持本地模式。
- **AI 模型与用量面板**：新增「模型与用量」独立面板（帮助与支持菜单 →「模型与用量」），把各 AI 功能的调用量、Token 消耗、耗时与预估费用汇总到同一口径：可按功能、模型与供应商筛选，查看每日趋势与功能归因，「请求日志」逐条列出时间、模型、Token 与费用，数据每 5 秒自动刷新。可为常用模型配置计价规则（按 Token 或按次）并设置月度预算，接近或超出预算时在面板中给出预警。
- **跨应用拖入导入（macOS）**：macOS 上可以直接把微信、照片等其他桌面应用里尚未保存到磁盘的文件拖进 OrcaBox：应用会以「文件承诺」方式在拖放结束时接收原始文件，并按普通导入流程处理入库。Windows 版请先把文件保存到磁盘后再拖入，普通拖入导入不受影响。
- **Shift+空格 快速搜索插件**：主窗口按 Shift+空格 直接弹出插件搜索框，打开时只是一个输入框，输入关键词后才出结果，不会一上来铺满插件列表。支持中文、英文、全拼与拼音首字母（「视频」「video」「shipin」「spzj」都能搜到「视频质检」），单个字母即可联想；↑/↓ 选择、回车执行插件主动作、Esc 关闭。拼音只从插件名称生成，描述只参与直接子串匹配，打几个无关字母不会把所有插件都联想出来。在「来源管理」「任务中心」等没有工具栏插件按钮的分区同样可用；绑定可在快捷键面板改键，工具栏 Puzzle 入口保持原有完整列表与管理操作。
- **插件独立分发**：自 1.4.2 起，外部插件不再随安装包捆绑（`resources/bundled-plugins` 不再随包拷贝），改为独立开发、独立供应：通过插件目录 feed（`plugin-index.json` + 远程 zip，安装时做 https/SHA-256/解压限额校验）或手动安装 zip 获取，后续在插件中心独立升级。既有用户已播种的 bundled 插件保持可用，仍可在插件中心停用/卸载；「图片批量裁剪」已转为内置插件随应用分发。

## 优化改进

- **通知堆叠卡组**：同一时间出现多条通知时，它们收起成一张露出侧边的卡组，不再互相遮挡或堆满屏幕；鼠标悬停即弹开展示全部，移开后继续收起。悬停某条通知会暂停它的自动消失倒计时，按 Esc 可把展开的卡组重新收起；设置常驻的通知保留原行为。倒计时改由组件外部统一管理，列表滚动或切换分区不会让通知提前消失或重复计时。macOS 与 Windows 表现一致。
- **模型与用量面板改版**：面板按统一仪表盘设计语言重排——侧栏改为带圆角的悬浮玻璃底座，内容区滚动时顶部出现渐进模糊；概览指标卡与分段切换换成轻量胶囊交互，切换时带滑动动画。趋势图撑满宽度并支持悬停查看单日明细，概览新增两种视图：功能分布用环形图展示各功能请求占比（悬停扇区高亮并显示明细），模型排行按 Token 消耗列出前几名模型的请求数、Token 与成本。同时清理了各板块标题下的冗余说明文字，修正了请求日志表头滚动时与内容重叠的问题，并把「当前路由」状态移到侧栏底部。改动只影响面板外观与交互，统计口径与数据完全不变。

## 问题修复

- **Windows 资料库路径显示**：左上角资料库切换区现在显示当前资料库的完整路径，长路径可悬停查看；盘符根目录与 UNC 共享根目录会正确保留。此显示改动不移动或修改素材文件。
- **Windows 独立面板标题栏融合**：设置、插件中心、模型与用量等独立面板的最小化/关闭控件区域与各自面板表面衔接，并保留可靠点击区域；模型与用量面板的顶部渐进模糊也延伸到控件下方。
- **来源目录子文件夹封面不显示**：修复子文件夹卡片里的封面加载不出来、只剩模糊色团的问题——文件夹卡片的磨砂玻璃层会模糊下方已加载的封面，现在来源目录卡片不再叠该玻璃层；同时修正单张封面被空白文档占位卡盖住的问题。本次为同一 1.4.2 版本的修复重打包（macOS），下载并覆盖安装即可。

- **视频快捷操作旋转失败**：修复部分 MP4 视频在快捷操作中旋转时报 `codec none` 或无法写入文件头的问题。旋转现在只选择可播放的视频与音频流，并保留元数据和章节信息。
- **视频方向无损调整**：支持 MP4、MOV 和 M4V，通过更新容器显示方向矩阵调整视频方向，音视频使用 `-c copy` 复制，不重新编码、不降低原始质量，也不生成预览代理视频。
- **相机竖拍照片缩略图方向**：读取照片中的 EXIF Orientation，在生成普通图片缩略图前应用显示方向，再执行缩放，修复“打开预览是竖直的、网格缩略图却是横向”的问题。网格卡片比例也按同一显示方向计算，避免竖图缩略图被放进横向卡片。
- **自动方向与原图旋转的边界**：自动方向处理只更新 OrcaBox 的派生缩略图缓存，不修改照片原始像素；Finder、其他应用和重新索引后的原图方向保持不变。需要真正旋转本地原图时，仍使用快捷操作中的向左或向右旋转。
- **DOCX 等文档误归为工程**：修正旧索引中 Word、PowerPoint、Excel 等文档被保存为“工程”的问题。升级并打开资产库时会按统一文档扩展名规则自动纠正已有记录，DOCX 现在显示在“文档”分类；真实工程格式保持不变，也不会移动或改写原始文件。
- **安装任务关闭时状态残留**：关闭应用时会取消活动的外部语音运行时安装任务，并等待安装流程完成清理后再关闭数据库和服务容器，减少退出时的残留状态。

## 获取更新

1.4.2 安装包发布后，可在 OrcaBox 的“设置 → 概览 → 关于与更新”中检查更新，也可从“帮助与支持”打开同一入口。macOS 自动更新使用架构匹配的 ZIP 载荷，人工安装使用 DMG；Windows 自动更新使用 NSIS 安装器与对应 blockmap，Portable 版本继续作为单独的手动下载资产。

## 平台差异与当前开发状态

| 项目               | macOS                                                                   | Windows                                                                          |
| ------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 视频快捷旋转       | 使用 FFmpeg 容器显示方向矩阵与码流复制                                  | 使用同一共享逻辑；FFmpeg 运行时需可用                                            |
| 支持格式           | MP4、MOV、M4V                                                           | MP4、MOV、M4V                                                                    |
| 视频质量           | 不重新编码，保留原始音视频码流                                          | 不重新编码，保留原始音视频码流                                                   |
| 预览代理           | 不生成视频代理                                                          | 不生成视频代理                                                                   |
| 相机照片 EXIF 方向 | 缩略图应用方向，原图不变                                                | 使用同一共享缩略图逻辑，原图不变                                                 |
| 语音安装关闭       | 取消任务并等待清理完成                                                  | 取消任务并等待清理完成                                                           |
| 图片批量裁剪       | 同一套面板/主进程裁剪逻辑；AI 本地视觉模型 Metal 加速                   | 同一套面板/主进程裁剪逻辑；AI 本地视觉模型可用时离线识别，云端走 OpenAI 兼容 API |
| 视频质检           | 同一套面板/主进程质检管线；ffmpeg 单遍解码 + 本地视觉模型 Metal 加速    | 同一套面板/主进程质检管线；ffmpeg 单遍解码 + AI 本地模型可用时离线识别           |
| AI 打标签与描述    | 共享本地/云端识别路由；云端通过 OpenAI 兼容或供应商适配请求视觉模型     | 使用同一共享路由与请求路径；需在 Windows 上配置可用的远程端点与密钥              |
| 通知堆叠卡组       | 收起/弹开、悬停暂停倒计时、Esc 折叠均为共享渲染层实现                   | 同一共享实现；仅窗口圆角与投影随平台窗口边框略有差异                             |
| 模型与用量面板     | 悬浮玻璃侧栏底座顶部贴窗，红绿灯嵌入玻璃内（trafficLightPosition 下移） | 无边框窗口自定义按钮位于内容区右上，底座四周等距内缩；面板交互与图表视图一致     |

- 视频旋转是共享主进程路径，macOS 与 Windows 使用相同的方向计算、流选择和安全替换流程；两端的 FFmpeg 运行时由各自平台的媒体运行环境提供。
- 本文档记录 1.4.2 开发分支中的修复与优化。安装包、自动更新清单和签名验收需要在对应平台完成构建后再发布。
